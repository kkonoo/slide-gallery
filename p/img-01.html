메인 그림 img-01

그림 한 장을 크게, 아래에 캡션. 그림 안 지점을 A·B·C 원으로 짚거나, 아래에 작은 그림을 한 줄로 놓아요.

이 시안

그림 + A·B·C 표시 · 옆에 설명 목록

슬라이드 제목: 종양 경계의 세 클러스터를 봐 주세요

예시 pptx 받기 (시안 3개)

언제 쓰나

분석 그림·사진·화면 캡처 한 장이 주장을 담을 때요. 관련 그림 3–4장을 보조로 비교할 때는 아래에 썸네일 줄을 둬요.

이럴 땐 다른 패턴

  • 숫자 몇 개로 된 그래프면 PowerPoint 차트 그래프 한 장
  • 그림 옆에 설명 목록을 두려면 좌우 나눔 으로 좌우를 나눠요.

구성

  1. 그림을 비율 그대로 크게. 테두리는 얇은 회색 선 하나.
  2. 봐야 할 곳에 A·B·C 원 표시, 설명은 옆 목록이나 발표자 노트에.
  3. 아래 캡션 한 줄 (데이터 출처, n, 조건).
  4. 썸네일이 있으면: 위에 키워드 소제목, 아래에 같은 크기 그림 3–4장, 번호 + 한 줄 캡션, 선택한 하나만 테두리.

지킬 것

  • 메인 그림은 하나.
  • 썸네일은 3–4장, 높이는 메인의 1/4 이하, 간격은 같게.
  • 표시는 6개 이내.

하지 말 것

  • 그림 비율을 늘리거나 줄여 찌그러뜨리지 않아요.
  • 썸네일마다 다른 색 테두리나 진한 그림자를 쓰지 않아요.
  • 그림을 통째로 붙이고 "보시다시피…"라고만 하지 않아요.

사진 위 문장 img-02

사진 한 장을 꽉 채우고 어두운 면 위에 메시지 한 문장. 사진은 흑백으로 낮춰요.

이 시안

아래 띠 · 메시지 + 보조 줄 + 출처

슬라이드 제목: 면역항암제 반응은 환자마다 크게 다르다

예시 pptx 받기 (시안 3개)

언제 쓰나

발표 첫머리나 섹션이 바뀌는 곳에서 한 문장을 던질 때요. 사진은 분위기를 전하고, 글은 한 문장만.

이럴 땐 다른 패턴

  • 수치 · 근거를 같이 보여야 하면 메인 그림
  • figure 를 근거로 보여 주면 Figure + 결론

구성

  1. 본문 영역을 사진으로 꽉 채워요 (비율은 지키고 잘라요).
  2. 사진은 흑백으로, 밝기를 낮춰요.
  3. 아래 띠나 왼쪽 면에 반투명 검정을 깔고 메시지 한 문장 + 보조 한 줄.
  4. 키워드 하나만 강조색, 출처는 오른쪽 아래 아주 작게.

지킬 것

  • 메시지는 30자 안팎 한 문장, 보조 줄은 40자 이내.
  • 글자 면은 사진의 40% 이하.

하지 말 것

  • 보호 면 없이 복잡한 사진 위에 글을 얹지 않아요.
  • 흐리거나 늘린 사진을 쓰지 않아요.

PowerPoint에서

사진을 고르고 그림 서식 > 색 > 채도 0, 그림 수정 > 밝기를 낮춰요. 예시 pptx 는 이미 바꾼 사진이 들어 있어요.

# HaLab 슬라이드 갤러리

하고 싶은 말에 맞는 슬라이드를 고르는 학생용 자료예요. 상황을 고르면 추천 패턴, 같은 내용으로 만든 여러 시안,
만들 때의 팁을 볼 수 있어요. 시안은 PowerPoint 파일로 받아 그대로 고쳐 써도 돼요.

- 사이트: https://kkonoo.github.io/slide-gallery/
- 예시 슬라이드의 내용과 숫자는 설명을 위해 만든 것이에요.
- 빈 서식(.potx)은 potx/<색>/ 에 있어요. 사이트 첫 화면에서 고른 색으로 받을 수 있어요.
- 이 저장소는 만들어진 사이트(HTML · 그림 · 예시 pptx · 서식)만 담고 있어요. 직접 고치지 말고 원본에서 다시 만들어요.

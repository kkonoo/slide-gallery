항목 나열

같은 모양의 항목 여러 개를 보여 주고 싶어요

이럴 때

순서, 할 일, 체크리스트, 자주 하는 실수, 용어 설명처럼 같은 모양의 항목이 여러 개 있을 때예요. 슬라이드에서 가장 자주 만나는 상황이에요.

들어가는 것

  • 항목마다 짧은 제목(키워드)과 설명 한두 줄.
  • 필요하면 앞에 시간·번호 같은 짧은 값.
  • 꼭 기억할 문장 하나는 따로 빼서 강조 면에.
  • 코드나 폴더 구조는 글자 그대로.

강조할 것

이번 장에서 가장 중요한 항목 하나만 옅은 면으로 짚어요. 모든 항목을 굵게 하면 아무것도 눈에 들어오지 않아요.

고르는 법

  • 항목마다 제목 + 설명이면 → 행 구분 리스트
  • 제목 없이 짧은 문장 몇 줄이면 → 문장 목록
  • 꼭 기억할 공식·문장 하나를 띄우려면 → 강조 면
  • 코드·명령어·폴더 구조면 → 코드
  • 항목 사이에 순서가 있고 그 순서가 메시지면 순서·과정 쪽이 맞아요.

팁

  • 카드를 여러 개 늘어놓지 말고, 가로선으로 줄을 나눠요. 카드가 많으면 레고처럼 보여요.
  • 글머리 기호(•)를 줄마다 달지 않아요. 번호가 필요하면 숫자만 쓰지 말고 네모·원 배지로.
  • 강조할 문장은 본문 안에서 굵게 하지 말고 밖으로 빼서 따로 둬요.
  • 글은 짧게. 문장보다 짧은 구절, 본문 3–5줄. 할 말은 발표자 노트에 적어요.
  • 디자인하기 전에 글부터 줄여요. 필요 없는 항목은 보충 슬라이드로.

추천 패턴

행 구분 리스트 list-01

항목을 가로선으로 줄을 나눠 쌓아요. 줄마다 번호(또는 표시) + 제목 + 설명.

시안 10개

문장 목록 text-01

짧은 문장 몇 줄. 줄 앞 몇 단어만 진하게, 나머지는 중간 회색.

시안 2개

강조 면 text-02

옅은 색 면 하나에 제목, 핵심 한 줄, 짧은 설명, 출처를 넣어요.

시안 3개

코드 code-01

옅은 회색 면에 고정폭 글꼴(D2Coding)로 코드·명령어·폴더 구조를 글자 그대로 보여 줘요.
